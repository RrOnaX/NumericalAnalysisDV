# Задача 1. Локализация корней и метод половинного деления

## Этапы работы
1. Построен график функции и выбраны три интервала со сменой знака на концах.
2. Найдены приближенные значения всех трех корней методом половинного деления.
3. Выведены журналы итераций для каждого корня.
4. Проведено сравнение фактического числа шагов с теоретической оценкой.
5. Найдены точные корни разложением на множители и посчитаны абсолютная и относительная погрешности.

## Результаты
Первый корень: точный 1.0, найденный 1.0000000002, итераций 31, погрешности 2.10 на десять в минус десятой степени.
Второй корень: точный 2.0, найденный 2.0000000003, итераций 31, абсолютная погрешность 2.56 и относительная 1.28 на десять в минус десятой степени.
Третий корень: точный 3.0, найденный 3.0000000002, итераций 31, абсолютная погрешность 1.63 на десять в минус десятой и относительная 5.43 на десять в минус одиннадцатой степени.

## Вывод
Методом половинного деления найдены все три корня с заданной точностью, а число итераций на каждом интервале составило 31 шаг и совпало с теоретической оценкой.
