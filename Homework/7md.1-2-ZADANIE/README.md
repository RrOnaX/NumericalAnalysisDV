# Матрицы, линейные преобразования и визуализация в Python

Практическая работа по применению матриц преобразований (поворот, отражение, масштаб, перенос в однородных координатах) с использованием библиотек NumPy и Matplotlib.

## Состав работы

### Задача 1. Поворот и отражение правильного шестиугольника
- **Что сделано:** построены вершины правильного шестиугольника радиусом 1 с замкнутым контуром. Выполнены поворот на 45 градусов против часовой стрелки и зеркальное отражение относительно прямой y = x. Все три контура построены на одном графике.

### Задача 2. Композиция преобразований и обратное преобразование
- **Что сделано:** сгенерированы 200 случайных точек в квадрате от -2 до 2. В однородных координатах 3x3 выполнена композиция из масштабирования (1.5 и 0.5), поворота на 60 градусов и переноса на вектор (1, -1). Затем применены обратные матрицы в обратном порядке и выполнена проверка совпадения точек через np.allclose с точностью 1e-12.
