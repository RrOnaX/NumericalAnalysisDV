# Сравнение способов создания списка квадратов: время и память

Замер производительности и расхода памяти для трёх подходов к генерации списка квадратов чисел от `0` до `N-1` на Python.

## Что сравнивается
1. Обычный цикл `for` с методом `.append()`
2. Списочное включение (`list comprehension`)
3. Функциональный подход `list(map(lambda ...))`

## Как проводились замеры
- **Размеры данных:** $N = 100\,000$ и $N = 1\,000\,000$.
- **Время (`timeit`):** для каждого варианта выполнено 5 прогонов (`repeat=5`), взят минимальный результат и переведён в миллисекунды.
- **Память (`tracemalloc`):** зафиксировано пиковое потребление памяти в мегабайтах при создании списка.
- **Визуализация (`matplotlib`):** построены два графика рядом — линейный для времени и столбчатая диаграмма для памяти.

## Выводы
- **По памяти:** все три способа тратят практически одинаковый объём памяти (~3.8 МБ для 100 тыс. элементов и ~38.6 МБ для 1 млн), так как итоговый объект в памяти один и тот же.
- **По времени:** быстрее всего работает `list comprehension` (выполняется на уровне C без лишних вызовов методов), а `map + lambda` оказывается самым медленным из-за накладных расходов на вызов `lambda` на каждой итерации.
