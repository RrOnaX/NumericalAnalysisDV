# Основы NumPy: массивы, типы данных, формы и базовые операции

В этом репозитории находятся решения практических задач (1–10) по изучению библиотеки NumPy, работе с памятью и операциям над многомерными массивами.

## Выполненные задачи

* **Задача 1:** Сравнение скорости вычисления суммы через циклы Python и встроенный метод `sum()` в NumPy.
* **Задача 2:** Разница между обычным и целочисленным делением, а также переполнение типа `int8`.
* **Задача 3:** Сравнение точности `float32` и `float64` и границы их применения в численных методах.
* **Задача 4:** Явное указание `dtype` при создании массивов и расчёт экономии памяти (`nbytes`).
* **Задача 5:** Последовательное изменение формы массива через `reshape` и проверка целостности данных.
* **Задача 6:** Различия между `ravel()` (создание view) и `flatten()` (создание независимой копии).
* **Задача 7:** Добавление и удаление осей (`newaxis`, `squeeze`), транспонирование и broadcasting.
* **Задача 8:** Транспонирование матрицы через `.T` без копирования данных в памяти (`strides`).
* **Задача 9:** Разница между поэлементным (`*`) и матричным (`@`) умножением.
* **Задача 10:** Агрегирующие функции (`sum`, `mean`, `argmax`) вдоль осей `axis=0` и `axis=1`.
