Задача 1
С ростом размера массива ускорение увеличивается, так как накладные расходы на вызов C-функции в NumPy становятся ничтожными по сравнению с работой цикла в Python. Заметная разница более чем в десять раз стабильно проявляется уже начиная со ста тысяч элементов. Вариант с вызовом sum намного короче и читается мгновенно без ручного объявления переменной для накопления суммы.
Задача 2
NumPy выполняет расчет в десятки раз быстрее за счет векторизованных вычислений на уровне языка C. Результаты обоих способов совпадают с требуемой точностью, а небольшие расхождения в самых последних знаках возможны из-за разного порядка сложения чисел. Код с использованием готовых методов mean и std гораздо понятнее, чем ручной подсчет сумм квадратов в цикле.
Задача 3
Векторизованное вычисление в NumPy работает намного быстрее, поскольку устраняет миллион отдельных вызовов функции синуса и запись в список в цикле Python. Запись с использованием функций библиотеки полностью повторяет исходную математическую формулу, поэтому читается намного проще и избавляет от необходимости заранее создавать пустой список под результат.
Задача 4
Функция clip в NumPy многократно опережает обычный цикл, поскольку постоянные проверки условий сильно замедляют выполнение кода в Python. В данном массиве из миллиона чисел было изменено 659155 элементов, вышедших за заданные границы. Одна строка с вызовом clip намного лаконичнее и сразу раскрывает суть операции в отличие от громоздкого блока условий.
Задача 5
NumPy работает в десятки раз быстрее за счет обхода непрерывной памяти на уровне языка C без вложенных циклов. По количеству строк кода реализация на циклах занимает восемь строк, а вариант с библиотекой всего одну строку. Использование параметра axis делает код компактным и полностью исключает риск ошибиться в индексах строк и столбцов.
Задача 6
Механизм транслирования в NumPy позволяет вычесть строку средних значений из всей матрицы без создания промежуточных списков, что дает колоссальный прирост скорости. Выражение с вычитанием среднего по нулевой оси читается как простая математическая запись. Версия на циклах требует двух двойных проходов по массиву и гораздо сложнее для понимания.
Задача 7
Даже при двух отдельных проходах по массиву для поиска значения и его позиции библиотека NumPy работает на порядок быстрее одного прохода в цикле Python. Читаемость встроенных методов очевидно выше, так как задача считывается с первого взгляда без отслеживания временных переменных для максимума и индекса.
Задача 8
Булева индексация в NumPy работает значительно быстрее спискового включения и радикально экономит оперативную память, занимая около четырех мегабайт против семнадцати у стандартного списка. Синтаксис логических масок является стандартом для работы с массивами и читается так же легко и понятно, как и конструкция в чистом Python.
