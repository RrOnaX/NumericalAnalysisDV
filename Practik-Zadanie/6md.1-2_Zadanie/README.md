# Бенчмарки в Python: время, память и визуализация

Практическая работа по замеру производительности кода с помощью стандартных модулей `timeit` и `tracemalloc`, а также построению графиков в `matplotlib`.

## Состав работы

### Задача 1. Поиск элемента: `list` vs `set`
- **Суть:** замер времени 1000 проверок вхождения отсутствующего элемента (`-1`) для размеров коллекции $n = 100, 1\,000, 10\,000$.
- **Инструменты:** `timeit.repeat` (`repeat=5`, берётся минимум) и график с логарифмической шкалой по оси Y.
- **Результат:** поиск в `list` растёт линейно ($O(n)$), а в `set` остаётся константным ($O(1)$). На 10 000 элементов множество работает быстрее списка более чем в 3000 раз.

### Задача 2. Создание списка квадратов: цикл vs `list comprehension` vs `map + lambda`
- **Суть:** сравнение скорости работы и пикового потребления памяти при генерации списков длиной $100\,000$ и $1\,000\,000$ элементов.
- **Инструменты:** `timeit.repeat` для времени, `tracemalloc` для пиковой памяти и парный график (`subplots(1, 2)`) с линиями и столбцами.
- **Результат:** по памяти все три способа равны (определяется размером итогового списка), а по скорости лидирует `list comprehension`.
